DAS Master Node gateway

nginx is serving this page and routing /api/* to three isolated services. Build the Angular reference client (das-04-angular-client) and start the stack with WEB_ROOT=/path/to/dist/browser sh scripts/run-local.sh to get the real UI here.

  • /api/heartbeat (core-api, with service health)
  • /api/capabilities
  • /api/volatile-data (telemetry-service, micro-cached)
  • /api/spectrum/latest (spectrum-service)
  • /api/metrics (aggregated)
